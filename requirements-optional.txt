# Set OCR_ENGINE=paddle or OCR_ENGINE=auto in .env after installing.

# (see https://www.paddlepaddle.org.cn/ for wheels).
#
# If you already have tensorflow installed, pin numpy below 2 and use a
# scipy version that still supports numpy 1.x, otherwise the two frameworks
# will fight over numpy/protobuf versions:
